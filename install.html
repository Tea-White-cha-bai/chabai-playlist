茶白歌单 · 安装

Android

下载 APK（7.5 MB）
  1. 点上面的按钮下载
  2. 完成后点开安装（首次需允许「安装未知来源应用」）
  3. 桌面出现「茶白歌单」即可使用

已装旧版可直接覆盖安装，数据保留。

iPhone / iPad

  1. 用 Safari 打开本网站首页（微信、Chrome 内不能装）
  2. 等页面加载完，点底部「分享」
  3. 选「添加到主屏幕」→ 添加
  4. 桌面出现图标，点开即全屏使用

装好后可完全离线；数据存在本机，建议定期用设置里的「导出备份」保存。

功能说明

  1. 导入：设置 → 导入歌曲，支持粘贴文本、txt/csv/docx/xlsx、图片 OCR
  2. 排序：底部七个标签 —— 首页（导入顺序）/ 难度榜 / 歌名 / 歌手 / 分类 / 随机 / 榜单
  3. 勾选：勾上=已唱，勾选的歌沉到列表底部；「重置勾选」一键清空
  4. 难度：内置难度库 + 手动评星，点难度星级可改
  5. 卡面：长按任意歌 → 卡片图片设置，可设当前卡面 / 轮换图 / 覆盖图
  6. 联网：搜索框切到「联网」可搜歌；榜单页可拉网易云热歌榜
