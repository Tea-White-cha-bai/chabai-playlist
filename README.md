# 茶白歌单

个人歌单管理工具：难度排序 / 拼音排序 / 网易云榜单 / 自定义卡面。

## 下载

- **Android**：`chabai-6.0.apk`（直接安装，离线可用）
- **iPhone / iPad**：用 Safari 打开本仓库的 GitHub Pages 地址，点「分享 → 添加到主屏幕」，即可像 App 一样使用

## 功能

- 歌曲导入：粘贴文本、txt/csv/docx/xlsx、图片 OCR 识别
- 内置难度库 + 手动评星，按难度排名
- 排序：首页（导入顺序）/ 难度 / 歌名拼音 / 歌手拼音 / 歌手 / 随机 / 网易云榜单
- 三态：未唱 / 已唱，勾选即已唱，已唱自动沉底
- 卡面自定义：整体透明度、圆角、间距、图片、覆盖图起点、按歌手折叠
- 主题：深浅色、自定义背景图、磨砂卡片、图标透明度
- 数据本地保存，支持导入导出备份与回收站

版本：v6.0
